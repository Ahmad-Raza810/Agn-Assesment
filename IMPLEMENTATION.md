# Implementation Overview

This full-stack application implements a secure lead management system using Spring Boot with JWT-based stateless authentication for the backend and React 18 with Vite for the frontend. The backend follows a layered architecture with controllers, services, repositories, and DTOs, utilizing MapStruct for clean entity-DTO mapping and centralized exception handling for consistent API responses. MySQL serves as the persistence layer with Hibernate's auto-DDL for schema management, while Spring Security secures all admin endpoints with role-based access control. The frontend uses React Context for global state management (auth and toasts), Axios with automated JWT injection for API calls, and Tailwind CSS for a responsive modern UI. Real-time features include debounced search, interactive status filtering, and a comprehensive follow-up scheduling system with automatic status transitions. CORS is configured to allow cross-origin requests from the Vite dev server, and the application includes a DataInitializer component that seeds default admin users and sample data on first startup.
