# Implementation Overview

This full-stack lead management system uses Spring Boot with JWT stateless authentication on the backend and React 18 with Vite on the frontend. The backend follows a layered architecture with controllers, services, repositories, and DTOs, employing MapStruct for entity-DTO mapping and centralized exception handling for consistent API responses. MySQL with Hibernate auto-DDL serves as the persistence layer, while Spring Security enforces role-based access control on admin endpoints. The frontend leverages React Context for global state management, Axios with automated JWT injection for API calls, and Tailwind CSS for responsive UI design. Key features include debounced search, interactive status filtering, and a follow-up scheduling system with automatic status transitions. CORS is configured for cross-origin requests, and a DataInitializer component seeds default admin users and sample data on first startup.
